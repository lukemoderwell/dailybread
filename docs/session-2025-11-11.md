## Bug Fixes

### 1. Streak Calculation Bug

**Issue**: Streaks were inconsistently calculating, sometimes resetting unexpectedly even on consecutive reading days.

**Root Cause**: Database trigger was comparing `last_completed_date` with `CURRENT_DATE` (server time at trigger execution) instead of `NEW.date` (the actual session date). Timezone differences between user and server could cause streaks to break incorrectly.

**Fix**:
- **Database**: `supabase/migrations/011_fix_streak_calculation.sql`
  - Changed trigger comparison from `CURRENT_DATE` to `NEW.date`
- **Client**: `components/reading/reading-experience.tsx:437`
  - Explicitly set session date using `getLocalDateISO()` function
  - Ensures user's local date is captured, not server time

**Impact**: ✅ Streaks now calculate correctly regardless of timezone

---

### 2. Previous Reading Navigation Bug

**Issue**: Clicking "Previous Reading" would navigate to a random earlier session instead of the most recently completed one. Example: After completing John 2:22-3:11, clicking previous would show Proverbs instead of the session ending at John 2:21.

**Root Cause**: Navigation was ordering sessions by UUID `id`, which is not chronologically ordered. UUIDs are random and don't correlate with creation time.

**Fix**: `app/api/bible/sessions/route.ts`
- Changed all navigation queries from `.order("id", ...)` to `.order("completed_at", ...)`
- Lines affected: 44, 89-90, 98-99, 113

**Impact**: ✅ Navigation now follows chronological completion order

## Question Generation Refinement

### Family Member Notes Usage

**Issue**: Concern that family member notes might be used too frequently, making questions feel corny or overly prescribed.

**Solution**: Updated question generation prompt to provide clearer guidance on when and how to use notes. Notes now serve two purposes with a recommended ratio:

**1. Invisible Theme Selection (~70% of questions)**
Use notes to choose WHICH aspect of a multi-theme passage to explore, without explicitly mentioning the note:

- ✅ Passage covers obedience + courage + prayer
  - Child's notes: "struggling with listening to parents"
  - Question: "Why do you think obeying God is hard sometimes? What helps?"
  - (Note guided topic choice; question never mentions parents)

**2. Visible Natural Connections (~30% of questions)**
Occasionally make explicit references when genuinely natural and enhancing:

- ✅ Passage mentions shepherds + child loves animals → "If you were caring for sheep like in this passage..."
- ✅ Passage about courage + child plays sports → "When you face a tough moment in a game, what helps you be brave? How might that connect here?"
- ❌ "Since you like soccer, how is faith like scoring a goal?" (TOO FORCED)

**Key Principle**:
> Default to invisible theme selection. Make visible connections only when it genuinely enhances the question and feels natural, not forced.

**File Changed**:
- `app/api/bible/generate-questions/route.ts` (lines 63-99)

**Impact**: Questions will be personally relevant without feeling forced or predictable. Most questions use notes as an invisible guide, but occasional explicit connections keep it fresh and engaging.
